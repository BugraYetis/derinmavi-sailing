## 📌 Proje Hakkında

30 yıllık denizcilik tutkusuyla Demre/Antalya merkezli Derinmavi Yelken Okulu için geliştirdiğim kurumsal site. Denizcilik temalı tasarım, interaktif harita, GPS/AIS entegrasyonu ve deniz sinyal bayrakları ile navigasyon içeriyor.
